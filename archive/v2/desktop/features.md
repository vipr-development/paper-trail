# Desktop Application Features

The Vipr Desktop application provides a user-friendly interface for analyzing React code.

## Project Management

- Open and manage multiple projects
- Recent projects list
- Project settings and configuration
- Workspace management

## Visual Reports

View analysis results with rich visualizations:

- Interactive charts and graphs
- Trend analysis over time
- Comparative metrics
- Export to PDF/HTML

## Code Browser

Browse your codebase with integrated analysis:

- File tree with issue indicators
- Code viewer with syntax highlighting
- Jump to definitions
- Search and filter

## Issue Management

Manage and track issues:

- Issue list with filtering
- Severity-based categorization
- Mark as fixed or ignored
- Export issue reports

## Dashboard

Overview of your codebase health:

- Key metrics at a glance
- Health score
- Recent activity
- Quick actions

## Settings

Customize the application:

- Theme selection (light/dark)
- Report preferences
- Analysis options
- Integration settings

## Export Options

Export reports in multiple formats:

- JSON
- HTML
- PDF
- Markdown
