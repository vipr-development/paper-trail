# Installation

This guide covers installing Vipr in your project.

## Prerequisites

- Node.js 22.22.0 or later
- pnpm 8.0.0 or later (recommended) or npm

## Installing the CLI

Install Vipr globally:

```bash
npm install -g @vipr/cli
```

Or with pnpm:

```bash
pnpm add -g @vipr/cli
```

Or install locally in your project:

```bash
npm install --save-dev @vipr/cli
```

```bash
pnpm add -D @vipr/cli
```

## Verify Installation

Check that Vipr is installed correctly:

```bash
vipr --version
```
