# Backlog of things to address

## It's imperative that we identify why there are so many anti-patterns in an application. It is not clear what the difference is between anti-patterns and issues. If I go to the Health Overview of the initial assessment modal, I see, for example, 1,304 issues in the application being analyzed that are critical. If I go to anti-patterns, I see 7,966 issues. Both of these numbers are very high, which in some ways seems to point to the possibility that we have some issues with our algorithms being too greedy in our analyzers. More importantly, it's not clear what the difference is between an anti-pattern and an issue, so we should explore that.

This especially applies to the action items that are listed on the action planning view in the assessment modal.
