# Testing Guides

Documentation for testing and verifying Vipr VSCode Extension functionality.

## Available Guides

- [User Testing Guide](./user-testing) - Step-by-step feature testing for end users
- [Developer Testing Guide](./developer-testing) - Unit and integration testing for contributors (in progress)

## Testing Scope

### User Testing

End-to-end feature verification including:

- Command execution
- Dashboard functionality
- AI integration
- Storage and history

### Developer Testing

Code-level testing including:

- Unit tests
- Integration tests
- E2E tests with VSCode Test Runner
- Performance benchmarks
