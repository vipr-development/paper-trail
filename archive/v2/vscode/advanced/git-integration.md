# Git Integration

> **Status:** Planned Feature

This feature is currently in development.

## Overview

Git integration will provide:

- Blame-based attribution showing who introduced issues
- Commit-level quality tracking
- Historical comparisons across commits
- Integration with regression detection

## Current Status

The foundation for git integration is implemented in:

- [SQLite Storage](./sqlite-storage) - Historical data storage
- [Phase 24 Documentation](../../feature-development/vscode-extension/phase-24-temporal-regression-detection) - Temporal analysis

## Coming Soon

- Full git blame attribution
- Commit-based navigation
- Author accountability features
- Team collaboration insights
