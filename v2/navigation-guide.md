## Quick Navigation Tips

### Finding What You Need

**I want to...**

- **Get Vipr running** → Start with "Getting Started" section
- **Use Vipr from the command line** → Go to "User Guides" → "CLI Interface"
- **Use Vipr in VSCode** → Go to "User Guides" → "VSCode Extension" → "User Guide"
- **Troubleshoot an issue** → Go to "User Guides" → "VSCode Extension" → "Troubleshooting"
- **Understand how Vipr works** → Go to "Architecture & Development" → "Core Architecture"
- **Contribute to Vipr** → Go to "VSCode Extension Development" or "Code Analysis Systems"
- **Look at old documentation** → Go to "Archive"
