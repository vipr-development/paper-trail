# VSCode Extension Installation

Install the Vipr VSCode extension to analyze your React code directly in your editor.

## Installation

### From VSCode Marketplace

1. Open VSCode
2. Go to Extensions (Cmd+Shift+X or Ctrl+Shift+X)
3. Search for "Vipr"
4. Click Install

### From VSIX File

```bash
code --install-extension vipr-x.x.x.vsix
```

## Verify Installation

After installation, you should see:

- Vipr icon in the Activity Bar
- Vipr commands in the Command Palette (Cmd+Shift+P or Ctrl+Shift+P)
