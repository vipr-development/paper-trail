# VSCode Extension Features

The Vipr VSCode extension brings powerful code analysis directly into your editor.

## Real-time Analysis

Analyze your code as you type with real-time feedback on:

- Security issues
- Accessibility problems
- Performance concerns
- Code complexity

## Inline Diagnostics

See issues directly in your code with:

- Squiggly underlines for problems
- Hover tooltips with detailed explanations
- Quick fixes for common issues

## Command Palette

Access Vipr features through the Command Palette:

- `Vipr: Analyze Current File`
- `Vipr: Analyze Workspace`
- `Vipr: Show Reports`
- `Vipr: Clear Analysis Cache`

## Side Panel

View analysis results in a dedicated side panel:

- Summary of all issues
- Filter by severity
- Navigate to problems in code
- Export reports

## Status Bar

Quick overview of your codebase health:

- Total issues count
- Severity breakdown
- Analysis status
