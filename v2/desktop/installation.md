# Desktop Application Installation

Install the Vipr Desktop application for a visual interface to analyze your React code.

## Download

Download the latest version for your platform:

- [macOS](https://vipr.dev/download/macos)
- [Windows](https://vipr.dev/download/windows)
- [Linux](https://vipr.dev/download/linux)

## macOS Installation

1. Download the `.dmg` file
2. Open the `.dmg` file
3. Drag Vipr to your Applications folder
4. Open Vipr from Applications

### First Launch

On first launch, you may see a security warning:

1. Open System Preferences > Security & Privacy
2. Click "Open Anyway" next to the Vipr message
3. Confirm you want to open the application

## Windows Installation

1. Download the `.exe` installer
2. Run the installer
3. Follow the installation wizard
4. Launch Vipr from the Start menu

## Linux Installation

### Debian/Ubuntu

```bash
sudo dpkg -i vipr-x.x.x.deb
```

### AppImage

```bash
chmod +x vipr-x.x.x.AppImage
./vipr-x.x.x.AppImage
```

## Verify Installation

Launch the application and verify you see the welcome screen.
